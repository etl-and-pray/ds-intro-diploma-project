# Итоговый проект: Анализ пользовательского поведения и проверка гипотез (Product Analytics)

## Описание проекта
Проект посвящен глубокому анализу веб-трафика и пользовательского поведения с целью оптимизации маркетинговых каналов и ответа на ключевые вопросы продуктовой команды. В работе выполнен разведочный анализ данных (EDA), очистка датасета, а также статистическая проверка гипотез о конверсии (CR) в целевые события.

## Основные этапы работы
1. **Подготовка и предобработка данных:**
   * Оценка полноты, структуры и чистоты датасета.
   * Базовая чистка: обработка дубликатов, пропусков, типизация данных и удаление лишних атрибутов.
2. **Разведочный анализ (EDA):**
   * Анализ распределения ключевых атрибутов и их взаимосвязей.
3. **Проверка статистических гипотез:**
   * Сравнение органического и платного трафика по метрике CR (Conversion Rate).
   * Оценка различий в конверсии между мобильными и десктопными устройствами.
   * Анализ влияния географического фактора (города присутствия vs иные регионы) на целевые действия.
4. **Решение продуктовых задач:**
   * Определение наиболее целевых источников, кампаний и локаций (с учетом объема трафика и CR).
   * Анализ спроса и показателей конверсии по различным продуктам/категориям (автомобилям).
   * Оценка рентабельности и целесообразности масштабирования рекламы в социальных сетях.

* **Библиотеки:** Pandas, NumPy, SciPy / Statsmodels, Matplotlib, Seaborn
