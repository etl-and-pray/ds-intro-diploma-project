# Анализ трафика сервиса подписки на авто: что конвертирует, а что нет

Продуктовая аналитика на данных веб-аналитики: 1,86 млн сессий и 15,7 млн событий. Нужно было понять, какие каналы, устройства, регионы и автомобили приносят заявки на подписку, и стоит ли вкладываться в рекламу в соцсетях.

## Ключевые результаты

| Вопрос | Ответ |
|---|---|
| Общая конверсия | **2,70%** (50 314 целевых сессий из 1 860 042) |
| Органика vs платный трафик | CR **4,04%** vs **2,19%**, органика лучше на **+83,9%** (p ≈ 0) |
| Мобильные vs десктоп | **2,60%** vs **3,10%**: различие значимо, но практически ничтожно (Cohen's h = 0,03) |
| МСК/СПб и области vs остальные регионы | **2,80%** vs **2,61%**: значимо, но практически ничтожно (h = 0,012) |
| Соцсети | CR **1,47%** против **2,92%** у остальных каналов (−49,8%), но это **14,7% всего трафика** |
| Лучшие модели по CR | Kia Rio (9,04%), Toyota Camry (8,72%), VW Polo (8,29%) |
| Лидеры по просмотрам | Skoda Rapid (442 779), Lada Vesta (404 150), VW Polo (318 264) |

**Выводы для бизнеса**
- Органику стоит усиливать: она конвертируется почти вдвое лучше платного трафика.
- Различия по устройствам и географии статистически значимы (на такой выборке значимо почти всё), но по размеру эффекта малы. Отдельную стратегию под них строить не нужно.
- Из соцсетей уходить не стоит из-за охвата. Нужно пересматривать креативы и аудитории и использовать их как верхний уровень воронки с ретаргетингом.
- У Mercedes-Benz много просмотров (475 765), но CR всего 3,82%: интерес есть, до заявки он не доходит.

## Что сделано

1. **Разметка таргета.** Из таблицы хитов (15,7 млн строк, читается чанками по 500 тыс.) собраны сессии с одним из 8 целевых событий (`sub_car_claim_click`, `sub_callback_submit_click`, `sub_submit_success` и др.). Таргет присоединён к таблице сессий.
2. **Очистка и признаки.** Удалены дубликаты, отброшен `device_model` (99% пропусков), пропуски заполнены. Созданы флаги `is_organic`, `is_mobile`, `is_social`, `is_target_geo` (регулярные выражения по городам Москвы, СПб и Подмосковья) и `is_geo_missing`.
3. **Агрегация хитов.** Для каждой сессии посчитаны `total_events`, `unique_pages`, `target_events`. Дубликаты хитов убраны в каждом чанке, объединение через LEFT JOIN.
4. **EDA.** Распределения, динамика визитов, CR по срезам, корреляции. Сильнее всего с целевым действием связаны глубина сессии (`total_events`, r = 0,21) и число уникальных страниц (r = 0,17).
5. **Расшифровка источников.** `utm_source` анонимизирован, поэтому каналы разнесены на «Платный», «Органика» и «Соцсети» по доле органических визитов и известному списку соцсетей.
6. **Проверка гипотез.** Двусторонний Z-тест для двух пропорций (α = 0,05), для каждой гипотезы также размер эффекта (Cohen's h), мощность теста и относительный lift. Сессии с неизвестной географией исключены из теста по регионам.
7. **Бизнес-вопросы.** Топ источников, кампаний, устройств и городов по объёму и по CR, оценка соцсетей, спрос на марки и модели авто (парсинг `hit_page_path`).

## Стек

Python · Pandas · NumPy · Matplotlib · Statsmodels (`proportions_ztest`, `proportion_effectsize`, `NormalIndPower`)

## Ограничения

- Конверсия по моделям авто засчитывается каждой модели, которую пользователь смотрел в целевой сессии, поэтому CR массовых моделей завышен. Надёжнее опираться на число уникальных сессий и абсолютное число заявок.
- Источники и кампании анонимизированы, глубина анализа рекламы ограничена.
- Для ~4,2% сессий география неизвестна.
- Данные о конверсиях взяты из системы веб-аналитики, пересчёт по другим моделям атрибуции не делался.
